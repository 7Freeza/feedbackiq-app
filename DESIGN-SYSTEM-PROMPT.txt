# Filosofía visual (OBLIGATORIA — no negociar)

Nombre interno del estilo: **“Vacío numérico”** (numeric void).

Principios duros:
1. **Espacio = estructura.** Separación vertical grande entre bloques. NO uses
   cards con borde, cajas grises, paneles glass, ni sombras de elevación.
2. **Sin glassmorphism. Sin blur. Sin glow. Sin neón.** Fondo sólido oscuro.
3. **Sin bordes decorativos** en contenedores. Los únicos “bordes” permitidos
   son: (a) línea inferior sutil en inputs/tablas (`rgba(255,255,255,0.06)`),
   (b) outline mint en `:focus-visible`.
4. **Números son el héroe.** KPIs en mono, tamaño brutal, color mint o ink.
   Un número principal puede ser `clamp(4.5rem, 14vw, 11rem)` y casi recortar
   el viewport (sensación de instrumento de medición / infinito).
5. **Poca tinta, mucho aire.** Mucho negro, tipografía clara, acentos mint y
   amber solo para estado (éxito / warning-error).
6. **Labels en mayúsculas tracking amplio** (eyebrow): xs, letter-spacing ~0.1–0.14em,
   color mute.
7. **Botón primario = bloque mint sólido, texto void, uppercase, sin border-radius
   redondeado exagerado** (preferible radius 0 o casi 0 — look rectangular limpio).
8. **Inputs = solo línea inferior**, fondo transparente, mono en números.
9. Fondo de atmósfera opcional: canvas de puntos grises muy sutiles (opacity ~0.35
   del canvas), movimiento casi imperceptible, color `rgba(138,147,166,a)`.
   Sin partículas brillantes. Respetar `prefers-reduced-motion`.
10. Sensación: laboratorio de datos / terminal de trading minimal / dashboard
    de métricas de elite. Frío, preciso, calmado. NO SaaS genérico 2024
    (nada de purple gradients, nada de bento boxes con shadow-xl).

# Layout

- Fondo `body` / `html`: `--void`.
- Contenido principal centrado: `width: var(--read); margin: 0 auto;`
- Padding vertical generoso: top ~space-xl, bottom ~space-3xl.
- Nav sticky top, padding horizontal alineado al read-width:
  `padding: var(--space-md) calc((100vw - min(72rem, calc(100vw - 3rem))) / 2);`
  Fondo: `linear-gradient(to bottom, var(--void) 60%, transparent)` — sin border-bottom.
- Brand: `Nombre<span style mint>Sufijo</span>` o palabra clave en mint.
- Bloques: clase mental `.block` con `margin-bottom: var(--space-2xl)`.
- Grids KPI: `repeat(auto-fit, minmax(10rem, 1fr))`, gap grande (space-xl / space-lg).
- Charts (si aplica): grid 1 col mobile, 2 col ≥900px; altura chart ~260–280px.
- Mobile ≤640px: reduce padding lateral a ~1.25rem; read-width = calc(100vw - 2.5rem).

/**
 * Campo de puntos sutil. Sin glow, sin neón.
 * color: rgba(138, 147, 166, alpha)  ← es --mute
 */
function initTokenField(canvas) {
  if (!canvas) return () => {};
  const ctx = canvas.getContext('2d');
  let w = 0, h = 0, dots = [], raf = 0, running = true;

  function resize() {
    const dpr = Math.min(window.devicePixelRatio || 1, 2);
    w = window.innerWidth; h = window.innerHeight;
    canvas.width = w * dpr; canvas.height = h * dpr;
    canvas.style.width = w + 'px'; canvas.style.height = h + 'px';
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    const n = Math.min(Math.max(Math.floor((w * h) / 14000), 40), 160);
    dots = Array.from({ length: n }, () => ({
      x: Math.random() * w, y: Math.random() * h,
      r: Math.random() * 0.8 + 0.4,
      vx: (Math.random() - 0.5) * 0.08,
      vy: (Math.random() - 0.5) * 0.08,
      a: Math.random() * 0.25 + 0.08,
    }));
  }

  function frame() {
    if (!running) return;
    ctx.clearRect(0, 0, w, h);
    for (const d of dots) {
      d.x += d.vx; d.y += d.vy;
      if (d.x < 0) d.x = w; if (d.x > w) d.x = 0;
      if (d.y < 0) d.y = h; if (d.y > h) d.y = 0;
      ctx.beginPath();
      ctx.fillStyle = `rgba(138, 147, 166, ${d.a})`;
      ctx.arc(d.x, d.y, d.r, 0, Math.PI * 2);
      ctx.fill();
    }
    raf = requestAnimationFrame(frame);
  }

  if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
    resize();
    for (const d of dots) {
      ctx.beginPath();
      ctx.fillStyle = `rgba(138, 147, 166, ${d.a * 0.6})`;
      ctx.arc(d.x, d.y, d.r, 0, Math.PI * 2);
      ctx.fill();
    }
    return () => {};
  }

  resize(); frame();
  window.addEventListener('resize', resize);
  return () => {
    running = false;
    cancelAnimationFrame(raf);
    window.removeEventListener('resize', resize);
  };
}
